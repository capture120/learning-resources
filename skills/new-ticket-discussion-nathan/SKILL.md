name: new-ticket-discussion-nathan
description: flow to discuss how to approach a new ticket.
---

First:
"please discuss this ticket with me. i want to understand the problem first, any relevant background context a beginner would need to understand so I can understand what the actual problem is first. then, tell me the core data model knowledge needed and whiteboard everything out. then lets talk about any invariants."

Then after discussion, ask to move on to this step:
"whiteboard out your thinking and map out the changes in pseudocode and talk through it. dont write any code yet. im checking your thinking and approach to this problem"
