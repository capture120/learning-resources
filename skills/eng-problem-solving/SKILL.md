** Intelligence for solving Engineering Problems **

state is represented as DB

functional programming is separation of state from computation

state is treated as an effect

Functional Programming is a means to Tackle Complexity

Domain Driven Design is a means to Tackle Complexity

abstractions useful & powerful

big brain is when you:

1. find an alternative abstraction
2. merge abstractions into single abstraction and have the brain capacity (working memory) to hold enough in your head to reason about → this is more efficient

in SWE we are building complexity layers then building interfaces connecting 

debugging becomes hard when number of layers is large

skill in building useful abstractions, connecting them via interfaces, isolating problems by seeing how many connecting interfaces break.

thinking of new abstractions and ways to handle problems / mantain software is the "solving hard problems" part.
