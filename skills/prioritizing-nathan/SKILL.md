# Thoughts for me 

It is generally better to act as if you have less time than you actually have
This exercise forces me to consider what's important, and discard lower prio things. 
It's an exercise to practice at working efficiently for whatever I'm doing. This is a skill to continuously develop.
This is helpful when there's a clear goal, metric, and definition of success. 
This helps me iterate quickly.

This is not as known, but it's estimated the amount of continuous work a human can do is ~90 minutes. It takes humans a long time to get into deep work and stay focused, so perhaps estimate how much I want to be done in that 90 minute frame. 

Naturally, I do not need to be working every single minute. I can take breaks as needed. 

But it's still better to maintain focus when possible. Breaks are doing nothing, not distracted by task. 

Set goals rigorously

Define success for those goals

Set metrics rigorously
